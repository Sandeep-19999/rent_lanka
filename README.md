# Rent Lanka

Sports Equipment Rental and Exchange Platform for Sri Lanka.

## Technologies

- Flutter Mobile Application
- React Admin Dashboard
- Firebase Backend
- Git & GitHub

## User Roles

- Sports Player
- Equipment Provider
- Administrator

## Admin payment portal

The separate React application lives in [`admin-web/`](admin-web/README.md).
See its README for Firebase configuration, trusted admin provisioning, local
startup, and the refund security-rule gate. Local verification results are in
[`admin-web/VALIDATION.md`](admin-web/VALIDATION.md).
